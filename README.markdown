# HACCP Studio Pro v9

Профессиональный конструктор журналов и листов контроля ХАССП.  
**NEURAL_ARCHITECT_PREMIUM++ · ASV_PROD**

Статический PWA, без сборки. Работает полностью офлайн после первого открытия.

## Что нового в v9

- Drag-and-drop граф (за заголовок) и строк прямо на листе
- Контекстное меню правой кнопкой: добавить/удалить/копировать графу или строку, сменить тип, очистить ячейку
- 9 готовых шаблонов (масла, температура, санитария, приёмка, тепловая обработка, уборка, дезинсекция, здоровье персонала, пустой)
- Вкладка «Технолог» — инструменты автора + ссылки на pH-метр, калькуляторы ужарки, FlowForge, HACCP Control, планер
- Кнопка обновления ↻ + автоматическая проверка при запуске и при появлении сети
- Минимум эмодзи в интерфейсе
- Полная резервная копия базы (шаблоны + настройки + документ)
- Миграция данных с v6/v8

## Публикация

Settings → Pages → Source: GitHub Actions, push в `main`.

## Офлайн

После первого открытия приложение работает без сети. Библиотеки PDF/PNG/Excel кэшируются автоматически.
